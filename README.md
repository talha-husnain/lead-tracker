# 🎯 Lead Tracker

A fast, private lead & meeting-follow-up tracker for BrandLux Media. No internet,
no sign-up, no monthly fee — it runs from a single folder on your computer and
keeps all your data local.

---

## ▶ How to open it

**Double-click `start.bat`** (or `index.html`). It opens in your web browser.
Tip: right-click `start.bat` → *Send to → Desktop (create shortcut)* so it's one
click away, and pin the browser tab.

> Best experienced in **Microsoft Edge or Google Chrome** (needed for the
> "auto-save to file" feature below).

---

## ✨ What it does

**The core you asked for**
- **Client profiles** — name, email, phone, company, title, source, and a clickable
  **LinkedIn / website link**.
- **Status column** with **color coding** — New → Contacted → Meeting Scheduled →
  Meeting Done → Proposal Sent → Negotiation → Won / Lost / On Hold.
- **Comments / notes** — a dated **notes timeline** per lead, so every meeting's
  notes and next steps are saved in order.

**The extras that make it powerful**
- ⏰ **Follow-up reminders** — set a *next follow-up date*; overdue and due-today
  leads are flagged in red/amber and summarised in a banner + dashboard, so you
  never forget one of your 7 weekly meetings again. Quick-schedule buttons
  (Today / +3 days / +1 week / +2 weeks) and optional **browser notifications**.
- ✉ **Follow-up email templates** — open a lead → *Follow-up email*, pick a
  template (after-meeting, proposal, check-in, break-up). It auto-fills the
  client's name and company; **Copy** it or **Open in your email app**, and it
  logs the send + snoozes the next follow-up a week out. Templates are editable
  in Settings.
- 📈 **Reports** — conversion funnel, leads by source, open value by stage, won
  revenue over the last 6 months, win rate, avg deal size, and a **monthly
  revenue goal** with a progress meter.
- 📊 **Dashboard** — open leads, follow-ups due, pipeline value, win rate, goal
  progress, pipeline breakdown, and recent activity at a glance.
- 🗂 **Four views** — Dashboard, a sortable/filterable **table**, a drag-and-drop
  **Kanban board** (drag a card to change status), and **Reports**.
- ⚡ **Bulk actions** — tick several leads to change status, set a follow-up,
  export, or delete them all at once.
- 🔎 **Search, filters & command palette** — find any lead instantly; filter by
  status/priority/source; sort by follow-up, value, and more. Press `/` to search
  or **Ctrl/⌘ + K** for the command palette.
- 💵 **Deal value & priority** — track potential revenue and Hot / Warm / Cold;
  capture **why deals are won or lost** for your reports.
- 🔗 **Links per lead** (proposals, contracts), 🏷 **tags**, ↩ **undo delete**,
  🌗 **dark mode**, and a fully **customizable pipeline** (rename stages, change
  colors, reorder, add your own).

### ⌨ Keyboard shortcuts
`N` new lead · `/` search · `Ctrl/⌘ + K` command palette · `1 2 3 4` switch
views · `?` help · `Esc` close.

## 💾 Your data & backups (important)

Your leads are saved automatically in your browser on this computer. To be safe,
use one of these so you can never lose anything:

1. **Data ▾ → Download backup (JSON)** — saves a backup file. Keep these in a
   folder (e.g. `d:\bd\Lead-tracker\backups`). The app reminds you weekly.
2. **Data ▾ → Link data file (auto-save)** *(Edge/Chrome)* — pick a file once
   (e.g. `lead-tracker-data.json`) and the app **auto-saves every change to that
   real file on disk**. This is the closest thing to a database file in a folder.
3. **Data ▾ → Export to CSV** — opens in Excel any time.

To move to a new computer: copy the folder, or use **Restore from backup**.

## 🧭 Quick start

1. Open the app → click **✨ Load sample data** to see it in action.
2. Explore the Dashboard, Leads table, and Board.
3. Click **🗑 Clear all data**, then add your real leads with **+ Add Lead**.
4. Set up **Link data file** or download a backup.
